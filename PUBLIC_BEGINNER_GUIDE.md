# Гайд для первого запуска

Этот файл предназначен для человека, который раньше не открывал Unity-проект.

## Windows

1. Откройте страницу репозитория и нажмите зелёную кнопку **Code**.
2. Выберите **Download ZIP**.
3. Распакуйте архив через правую кнопку мыши → **Извлечь всё**.
4. Установите Unity Hub с официального сайта Unity.
5. В Unity Hub установите редактор **6000.6.0f1**.
6. Откройте распакованную папку и дважды нажмите `PLAY-HORROR.bat`.
7. Когда Unity откроет проект, подождите окончания импорта, откройте `Assets/_Game/Scenes/Main.unity` и нажмите кнопку Play сверху.

Если рядом с launcher-файлом есть `MinecraftHorror.exe`, игра запустится сразу без редактора. EXE должен оставаться вместе с папкой `MinecraftHorror_Data` и остальными файлами сборки.

## macOS

1. Установите Unity Hub и редактор **6000.6.0f1**.
2. Скачайте ZIP и распакуйте его в удобное место.
3. Нажмите правой кнопкой на `PLAY-HORROR-Mac.command` и выберите **Открыть**.
4. Если macOS покажет предупреждение, снова выберите **Открыть** в системных настройках безопасности.
5. Unity Hub откроет проект. После импорта откройте `Assets/_Game/Scenes/Main.unity` и нажмите Play.

Готовое приложение macOS запускается этим же файлом, если папка `MinecraftHorror.app` лежит рядом с ним.

## Первое действие в игре

Нажмите **Singleplayer**, создайте мир и выберите Survival или Creative. Обычное управление — `WASD`, мышь, `Space`, `Shift`, `E`, `Esc`. Нажмите `J`, чтобы открыть журнал хоррор-дополнения. В Creative нажмите `E` и введите `horror:` в поиске.

## Частые проблемы

- Unity Hub сообщает, что версия не установлена: установите именно **6000.6.0f1**, а не только Hub.
- Окно долго загружает проект: первый импорт ассетов Unity может занять несколько минут.
- macOS не открывает `.command`: используйте правую кнопку → **Открыть**, а не обычный двойной щелчок.
- Windows блокирует неизвестный launcher: скачивайте файлы только со страницы этого репозитория и выберите **Подробнее → Выполнить в любом случае**, если доверяете источнику.

## Survival eggs

In Survival, use a horror: egg on a clear floor with enough space above it. One egg is consumed per successful spawn. The creature is real, can attack, and is saved with the world. Creative eggs are safe previews without damage or campaign rewards.
