# Базовая игра — публичное описание

Этот файл кратко описывает базовую Minecraft-подобную игру до хоррор-дополнения. Проект создаёт мир, блоки, предметы, интерфейс, звуки и существ средствами Unity и исходного кода.

Технические детали, временные журналы, локальные пути, пользовательские сохранения и служебная telemetry намеренно не распространяются. Для запуска используйте README.md и PUBLIC_BEGINNER_GUIDE.md.
