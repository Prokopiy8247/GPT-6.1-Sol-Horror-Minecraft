# Minecraft Recreation — The Quiet Below

Это существующий Unity-проект Minecraft-подобной игры с хоррор-дополнением **The Quiet Below / Низкий звон**.
Проект содержит исходники, Unity-настройки, ассеты и оба промпта:

- [Промпт основной игры](Unity_Minecraft_Prompt.md)
- [Промпт хоррор-дополнения](GPT-6.1-Sol_Unity_Minecraft_Horror_BlenderMCP_Prompt_v2.md)

## Самый простой запуск

### Windows

1. Установите Unity Hub и Unity Editor **6000.6.0f1**.
2. Скачайте этот репозиторий кнопкой **Code → Download ZIP** и распакуйте его.
3. Дважды нажмите `PLAY-HORROR.bat`.
4. Launcher запустит готовый `MinecraftHorror.exe`, если он находится рядом с launcher-файлом; в чистом исходном архиве он откроет проект в Unity.

Если вы получили отдельный архив готовой Windows-сборки, распакуйте его целиком и запускайте `PLAY-HORROR.bat`. Не выносите EXE из его папки с `_Data` и библиотеками.

### macOS

1. Установите Unity Hub и добавьте Unity Editor **6000.6.0f1**.
2. Скачайте и распакуйте репозиторий.
3. Дважды нажмите `PLAY-HORROR-Mac.command`. При первом запуске macOS может попросить подтвердить открытие файла: нажмите правой кнопкой → **Открыть**.
4. Launcher запустит найденный `MinecraftHorror.app`; если его нет, откроет проект в Unity Hub.

В этом репозитории хранится переносимый Unity-проект. Готовый бинарный пакет для конкретной ОС распространяется отдельно, потому что Unity-сборки и их библиотеки не являются частью исходников.

## Запуск из Unity

1. Откройте Unity Hub → **Add project from disk**.
2. Выберите папку, в которой находятся `Assets`, `Packages` и `ProjectSettings`.
3. Дождитесь импорта ассетов.
4. Откройте `Assets/_Game/Scenes/Main.unity` и нажмите **Play**.

Управление: `WASD` — движение, `Space` — прыжок/полёт в Creative, `Shift` — красться, мышь — обзор и действия, `E` — инвентарь, `J` — журнал хоррор-дополнения, `Esc` — пауза.

## Как начать хоррор-дополнение

В Survival нажмите `J`, найдите координаты **Survey Cairn**, прочитайте запись и заберите тайник. Затем изготовьте камертон и следуйте подсказкам журнала. В Creative откройте `E` и найдите `horror:` — там находятся 12 предметов и 7 яиц существ.

Подробный маршрут, рецепты, существа, ограничения и проверки описаны в [HORROR_PLAY_GUIDE.md](HORROR_PLAY_GUIDE.md) и [HORROR_FINAL_REPORT.md](HORROR_FINAL_REPORT.md).

## Сборка

Скрипты сборки находятся в `Tools/`. Для работы с Blender-ассетами используется исходный `UnityMinecraft.blend`; для обычного запуска Blender не требуется.

Исходники распространяются для ознакомления и самостоятельной сборки. Unity Editor, лицензия Unity и системные зависимости устанавливаются пользователем отдельно с официального сайта Unity.
